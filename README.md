# Kanban Board

Полнофункциональное kanban-приложение для командной работы с реалтайм-обновлениями.

## Стек

**Клиент**
- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Zustand (стейт-менеджмент)
- @dnd-kit (drag & drop)
- @tanstack/react-query
- framer-motion

**Сервер**
- Node.js + Express + TypeScript
- Prisma ORM + PostgreSQL
- Socket.io (реалтайм)
- JWT авторизация (access 15 мин + refresh 30 дней)
- Passport.js (OAuth — Google, GitHub)

## Функционал

### Авторизация
- Регистрация и вход по email + пароль
- OAuth через Google и GitHub
- Автоматическое обновление access-токена

### Воркспейсы и команды
- Создание воркспейсов
- Приглашение участников по email
- Роли: OWNER / MEMBER
- Настройки воркспейса: переименование, управление участниками, удаление

### Доски и колонки
- Неограниченное количество досок в воркспейсе
- Создание и удаление колонок (удаление — только для владельца)
- Цветной маркер у каждой колонки

### Карточки
- Создание, редактирование, удаление карточек
- **Приоритет**: URGENT / HIGH / MEDIUM / LOW
- **Срок выполнения**: кастомный date picker с навигацией по месяцам
- **Описание**: отображается прямо на карточке (краткий превью)
- **Исполнители**: назначение участников воркспейса на карточку
- **Метки (Labels)**: создание цветных меток и прикрепление к карточкам
- **Чеклист**: пункты с чекбоксами и прогресс-баром
- **Комментарии**: обсуждение прямо в карточке

### Drag & Drop
- Перетаскивание карточек между колонками и внутри колонки
- Визуальный индикатор места вставки
- Оптимистичное обновление UI

### Фильтрация
- Поиск по тексту карточки
- Фильтр по приоритету
- Фильтр по исполнителю
- Фильтр по сроку: просроченные / сегодня / эта неделя

### Реалтайм
- Все изменения (карточки, колонки) синхронизируются между вкладками и пользователями через Socket.io
- Индикатор подключения в шапке доски (зелёная точка)

### Интерфейс
- Тёмная тема
- Переключение языка RU / EN
- Адаптивность

## Локальный запуск

### Требования
- Node.js 18+
- Docker (для PostgreSQL)

### 1. База данных

```bash
cd server
docker-compose -f docker-compose.dev.yml up -d
```

PostgreSQL поднимется на порту **5434**.

### 2. Сервер

```bash
cd server
cp .env.example .env   # заполни переменные
npm install
npx prisma migrate dev
npm run dev
```

Сервер запустится на `http://localhost:5000`.

### 3. Клиент

```bash
cd client
npm install
npm run dev
```

Клиент запустится на `http://localhost:5173`.

### Переменные окружения (server/.env)

```env
DATABASE_URL="postgresql://postgres:postgres@localhost:5434/kanban"
JWT_SECRET="your-secret"
JWT_REFRESH_SECRET="your-refresh-secret"

# OAuth (опционально)
GOOGLE_CLIENT_ID=""
GOOGLE_CLIENT_SECRET=""
GITHUB_CLIENT_ID=""
GITHUB_CLIENT_SECRET=""

CLIENT_URL="http://localhost:5173"
SERVER_URL="http://localhost:5000"
```

## Использование

1. Зарегистрируйся или войди через Google / GitHub
2. Создай воркспейс
3. Пригласи коллег по email (кнопка «Invite» в сайдбаре)
4. Создай доску внутри воркспейса
5. Добавь колонки (например: To Do → In Progress → Done)
6. Создавай карточки, перетаскивай их между колонками
7. Открывай карточку для детального редактирования: приоритет, срок, описание, метки, чеклист, комментарии, исполнители
8. Используй фильтры (кнопка Filters в шапке доски) для поиска нужных карточек
9. Настройки воркспейса — иконка ⚙ рядом с названием воркспейса в сайдбаре
